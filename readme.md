# Student Performance Analytics System

## Project Overview

The Student Performance Analytics System is a Python-based
project designed to analyze student academic performance.

It processes student marks and attendance data to generate
useful insights about individual students and the class.

## Objectives

- Analyze student academic performance.
- Calculate total and average marks.
- Identify top-performing students.
- Analyze subject-wise and department-wise performance.
- Monitor student attendance.
- Generate a performance report.

## Technologies Used

- Python
- Pandas
- NumPy
- CSV Dataset
- Git and GitHub

## Features

1. Load student records from a CSV file.
2. Calculate total and average marks.
3. Assign grades to students.
4. Determine pass or fail status.
5. Calculate class average marks.
6. Identify the highest and lowest performers.
7. Analyze subject-wise performance.
8. Analyze student attendance.
9. Display the top five students.
10. Compare department performance.
11. Generate a student performance report.

## Dataset

The dataset contains 20 student records with the following columns:

- Student_ID
- Name
- Department
- Python
- Maths
- AI
- Attendance

## How to Run

1. Install Python.
2. Install the required libraries:

   pip install pandas numpy

3. Keep main.py, functions.py, and students.csv
   in the same project folder.
4. Open the terminal in that folder.
5. Run:

   python main.py

## Output

The system displays student statistics, grades, attendance
analysis, subject-wise performance, and top performers.

It also generates student_performance_report.csv.
